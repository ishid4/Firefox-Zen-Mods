How to install a mod
  1. Click Download on a mod to get its .zip.
  2. In Firefox, open the Library's Mods tab and click Install from zip….
  3. Pick the zip. CSS-only mods turn on right away; a mod with a script asks first.

Installed mods check this store for updates. Mods marked Script run with full access to Firefox: every script is reviewed before it's listed, but only install ones you trust.
